# Kamba Platform

Primeira base do ecossistema digital Kamba: uma experiência web responsiva para apresentar a visão do produto, os seus módulos e os canais de suporte.

## Estado atual

- Página institucional responsiva em HTML, CSS e JavaScript nativos.
- Navegação adaptada a dispositivos móveis e acessível por teclado.
- Secções para ecossistema, forma de funcionamento, visão e suporte.
- Sem dependências de build ou framework.
- A área de trabalho e outras funcionalidades transacionais ainda não estão implementadas.

## Estrutura

```text
.
├── index.html
├── README.md
└── assets
    ├── favicon.svg
    ├── css
    │   └── style.css
    └── js
        └── main.js
```

## Executar localmente

Abre `index.html` num navegador. Para desenvolvimento, também podes usar qualquer servidor estático local.

## Publicação no GitHub Pages

1. Abre **Settings → Pages**.
2. Em **Build and deployment**, escolhe **Deploy from a branch**.
3. Selecciona a branch `main` e a pasta `/(root)`.
4. Guarda e aguarda a publicação.
